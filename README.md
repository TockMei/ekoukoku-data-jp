# ekoukoku-data-jp

法務省 電子公告システムに掲載された公告を日次で収集し、加工せずに公開するデータリポジトリです。

## データの出所

法務省 電子公告システム（https://e-koukoku.moj.go.jp/）

同システムのコンテンツは法務省ウェブサイトの利用条件に従い、**公共データ利用規約（第1.0版）／PDL1.0** が適用されます。商用利用を含む二次利用が可能です。

出典：法務省ウェブサイト（https://e-koukoku.moj.go.jp/）

利用条件の原文は「[法務省ウェブサイトのコンテンツの利用について](https://www.moj.go.jp/hisho06_00280.html)」を参照してください。

## 更新頻度

日次。GitHub Actions による自動収集で、毎日 06:40 JST 前後に更新されます。

## 注記

本データは法務省電子公告システムの**公告期間中の掲載分**を日次で収集したものであり、法務省サイトでは掲載終了分を遡及取得できません。したがって収集開始日より前に掲載が終了した公告は本リポジトリにも含まれません。

法務省サイトの記載のとおり、掲載情報は会社法第946条第3項の規定に基づき電子公告調査機関から報告された事項を反映したものであり、公告の適法性・有効性を保証するものではありません。

## 収録ファイル

`data/koukoku.csv` — 全件収集・加工なし（UTF-8 with BOM）

| 列 | 内容 |
| --- | --- |
| 商号 | 公告を行う会社の商号 |
| よみ | 商号の読み |
| 法令の条項 | 公告の根拠となる法令の条項 |
| 公告アドレス | 公告本文が掲載されている URL |
| 公告開始日 | 公告期間の開始日 |
| 公告終了日 | 公告期間の終了日 |
| 所在地 | 会社の所在地 |
| 備考 | 備考欄 |
| 初回観測 | 本収集で最初に観測した日時 |
| 最終観測 | 本収集で最後に観測した日時 |
| 掲載終了検知 | 法務省サイト上で掲載終了を検知した日時 |

公告本文そのもの（PDF 等）は収録していません。`公告アドレス` の URL 先にある本文は各社が権利を有するため、利用にあたっては各社の条件に従ってください。

## 本リポジトリに含まれないもの

営業リスト等の加工済みデータ（`firms.csv` など）は本リポジトリには含まれません。収集元リポジトリで非公開のまま管理しています。
